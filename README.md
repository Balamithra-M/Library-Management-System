# Library Management System

## About the Project

The Library Management System is a console-based Java application that helps manage books and library members. It allows users to add books, search for books, issue and return books, and register members.

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Exception Handling
* Scanner Class

## Features

* Add new books
* Search for books by ID
* Display all books
* Issue books
* Return books
* Register library members
* Display all registered members
* Validate user input
* Prevent duplicate book and member IDs

## How to Run

1. Install the Java Development Kit (JDK).

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Open the terminal.

5. Compile the Java file:

   `javac LibraryManagementSystem.java`

6. Run the application:

   `java LibraryManagementSystem`
